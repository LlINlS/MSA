# Installation

## Stable release

To install Microservice attack simulation, run this command in your terminal:

```sh
uv add Microservice-attack-simulation
```

Or if you prefer to use `pip`:

```sh
pip install Microservice-attack-simulation
```

## From source

The source files for Microservice attack simulation can be downloaded from the [Github repo](https://github.com/LlINlS/Microservice-attack-simulation).

You can either clone the public repository:

```sh
git clone https://github.com/LlINlS/Microservice-attack-simulation
```

Or download the [tarball](https://github.com/LlINlS/Microservice-attack-simulation/tarball/main):

```sh
curl -OJL https://github.com/LlINlS/Microservice-attack-simulation/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd Microservice-attack-simulation
uv sync
```
